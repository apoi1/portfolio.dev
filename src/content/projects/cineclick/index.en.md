The backend half of a **movies full-stack application** — public on GitHub: a Spring Boot REST API for movies and reviews with the classic layered architecture (controller → service → repository), a Maven build, Docker support and a live deployment on Render.

## What's inside

- REST endpoints for movies and reviews (`MovieController`, `ReviewController`) — create, read, delete flows.
- Spring Data JPA repositories with a service layer doing the validation.
- Dockerized build; the first thing I reach for when going full-stack is **Java + Spring Boot**.

This is the stack I enjoy most for backend work: strong typing, clear layers, boring-in-a-good-way conventions.
