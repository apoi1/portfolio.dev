The site you're on — rebuilt from scratch as a **bilingual, dual-theme, motion-first portfolio** that stays 100% static on Netlify.

## How it's built

- **Astro 7 + Tailwind 4** — content collections drive every project card and this very case page: add a folder, drop images, write two markdown files, done.
- **three.js hero** — an interactive point-wave field that reacts to your pointer and follows the site theme.
- **GSAP + Lenis** — scroll choreography with full `prefers-reduced-motion` fallbacks.
- **EN / ES** with hreflang alternates; dark/light theme with zero flash-of-wrong-theme; JSON-LD, sitemap and per-locale metadata.
- The fun stuff: ⌘K command palette, custom cursor, magnetic buttons, live local time.
